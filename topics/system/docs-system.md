# Docs system

Owners: the rules in `/opt/nier/AGENTS.md:18-48`; the state of the system in
`/opt/overseer/topics/docs.md`; the generator `/opt/nier/tools/gen-index.sh`.

## Two repos, one rule

| Repo | Path | Readers | Holds | Source |
|---|---|---|---|---|
| overseer (rom618/overseer) | `/opt/overseer` | rom and work | machines, shared config, network, servers, work; footprint of personal apps | `topics/docs.md:17-19, 56-58` |
| 9s (rom618/9s) | `~/Playground/9s` | rom only | personal apps and projects (Camille, Minecraft, location, ...) | same |

The split follows Ciel's owner rule: rom sees all, work sees work and shared. It is a
convenience boundary, not security: both accounts can sudo (`topics/docs.md:80`). overseer
never links into 9s, and holds no personal detail, because a later personal/work server split
needs a history-free repo (`topics/docs.md:59-63`).

## Three levels

```
INDEX.md (generated)  ->  topics/<name>.md (Facts, Open, Log)  ->  detail where the work lives
                                                                   (code README, issue folder, git log)
```

Source: `topics/docs.md:23-25`. A page over about 150 lines becomes a folder
(`topics/<name>/index.md`); `gen-index.sh` warns (today: `topics/ciel.md`, 156 lines).

## How the docs stay current

| Mechanism | When | What it enforces | Source |
|---|---|---|---|
| Rule "update the owning page in the same turn" | every change | one owner, link elsewhere | `AGENTS.md:33-38` |
| `commit-msg` hook | every commit in a watched repo | a `Docs:` line naming the page | `nier/bootstrap/githooks/commit-msg:8-9` |
| `pre-commit` hook | every commit | gitleaks; in docs repos `gen-index.sh --check` (index and TODO up to date, front matter valid) | `nier/README.md:23-27` |
| `stop-docs-check.sh` | end of each Claude turn | edits left uncommitted or unpushed | `topics/nier.md:44-46` |
| `verified` and `source` front matter | each page | staleness is visible; warning after 30 days | `topics/docs.md:34-37, 81` |
| Ciel journal and inventory | nightly 00:30 | generated history and inventory, routed by owner | `topics/docs.md:27-30` |
| `nier context` | every session start | agents read indexes and TODO heads | `topics/docs.md:64-65` |

Watched repos (`/opt/nier/bootstrap/watched-repos.txt:5-12`): nier, dotfiles, overseer (shared),
9s (rom), ciel (shared), home-server (shared), camille (rom), aether (shared). Not watched:
mc-modpack, the issue folders, location.

## The generated parts

- `INDEX.md` of each repo: from the front matter of every topic and machine page. Never edited
  by hand.
- `TODO.md`: hybrid. Above the BEGIN marker, hand-written items with no topic; below, every
  topic's open `- [ ]` items, copied by `gen-index.sh` (`overseer/TODO.md:1-6, 105`).
- `journal/YYYY/MM/YYYY-MM-DD.md` and `inventory/index.md`: written by
  `/opt/nier/tools/ciel-docs-sync.sh` from Ciel's API (`/api/journal/day`, `/api/inventory`),
  owners `shared,work` to overseer and `rom` to 9s (`ciel-docs-sync.sh:46-74`), committed with
  `Docs: none (generated by Ciel)` and pushed (`:80-89`). It runs for rom only and exits 75
  (retry every 30 min) when Ciel is unreachable (`:6-7, 31-34`).

## Data flow around the docs

```
 agent edits a page -> commit (Docs: line, gitleaks, index check) -> push to GitHub
        |                                                  |
        +-- post-commit -> ciel-agent change -> Ciel hub journal
                                                    |
 00:30 rom's timer: ciel-docs-sync.sh <-------------+ (token ~/.config/ciel/token)
        -> journal/ + inventory/ in overseer and 9s -> commit -> push
                                                    |
 next session: nier context -> INDEX.md, TODO heads, machine page, Ciel brief
```

## What depends on what

- The docs feed needs: rom logged in on mikaela (user timer), Ciel reachable (home or tailnet),
  push access to GitHub, and no uncommitted work blocking a rebase (`ciel-docs-sync.sh:83-88`).
- work's sessions read overseer by absolute path `/opt/overseer`; they get no Ciel brief until
  work has a token (`topics/ciel.md:64`).
- The server has no copy of the docs (Open: `topics/docs.md:73`). Agents on roberta would see no
  machine page.

## Rules that protect content

- Never in any repo: secrets (write where they live), anything from private media (no paths,
  file names, titles, counts), and in overseer personal detail (`topics/docs.md:59-63`).
- Personal project on shared infrastructure: topic in 9s, only its footprint (stack, ports, jobs,
  checks) in overseer (`topics/docs.md:57-58`). This wiki follows the same split.
